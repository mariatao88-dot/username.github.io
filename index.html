FAQ Larix.CDB

Эта страница доступна публично по внешней ссылке.

Общие вопросы

Поддерживает ли Larix.CDB работу в оффлайн-режиме?

Нет. Larix.CDB — клиент-серверное приложение, требующее постоянного подключения к серверу БД. Работа без подключения невозможна.

Как обновить программу Larix.CDB?

Обновление выполняется вручную: удалите текущую версию через «Панель управления → Программы и компоненты», затем установите новую версию, полученную от администратора или техподдержки Larix. Настройки пользователя и данные Базы НСИ не удаляются при переустановке.

Где находятся лог-файлы программы?

Лог-файлы хранятся в сетевой папке, путь к которой задаётся администратором. Для быстрого доступа нажмите кнопку «Настройки» → «Открыть папку с логами».

Возможно ли работать в однопользовательском или многопользовательском режиме?

Larix.CDB поддерживает только многопользовательский режим с централизованной базой данных. Однопользовательский (локальный) режим не предусмотрен. Все пользователи работают с одной Базой НСИ через сервер приложений, что обеспечивает согласованность данных и контроль версий.

Измерения

Что такое Измерение в Larix.CDB?

Измерение — это срез данных Базы НСИ, в котором хранятся индивидуальные значения индикаторов (цен, норм времени и т.д.) для всех элементов. Вы можете создавать неограниченное количество измерений (например, «2025 Q1», «Проект X»), чтобы вести разные версии цен или норм в рамках одной базы. Все справочники (единицы измерения, статьи затрат) едины для всех измерений.

Работа с элементами и структурой

В чём разница между калькулируемым и некалькулируемым элементом?

Калькулируемый элемент — его цена и нормы автоматически рассчитываются на основе дочерних элементов (например, «Монолитные работы» = сумма бетона + арматуры + труда).

Некалькулируемый элемент — значения вводятся вручную (например, «Бетон В25» или «Армирование колонн»). Элементы последнего уровня иерархии (ресурсы) всегда некалькулируемые и не могут иметь дочерних записей.

Как создать новый элемент и прикрепить к нему дочерние записи?
1. Откройте нужный Классификатор  
2. Нажмите «Создать» → заполните шифр, наименование, отметьте «Калькулируемый»  
3. Сохраните элемент  
4. В окне «Дочерние записи» нажмите «Прикрепить» → выберите измерения, элемент и укажите расход
Можно ли удалить элемент, если у него есть дочерние записи?

Нет. Элемент нельзя удалить, пока у него есть дочерние или родительские связи. Сначала нужно открепить все связи через кнопку «Открепить». Удаление элемента происходит сквозь все измерения — нельзя удалить только из одного измерения.

Как работает копирование элемента?

При копировании создаётся новый элемент с уникальным шифром. Копируются все дочерние связи, признак «Калькулируемый» и значения индикаторов — только в выбранных измерениях. Текущее измерение автоматически включено в список копирования и нельзя его отменить.

Интерфейс и навигация

Как изменить порядок колонок в таблице?

Нажмите ПКМ по заголовку колонки → выберите «Выбор колонок» → перетащите поля в нужном порядке → нажмите «ОК». Если включена галочка «Сохранение внешнего вида», порядок сохранится после перезапуска.

Как быстро найти элемент по шифру или наименованию?

Нажмите ПКМ по заголовку колонки → выберите «Поиск» → введите текст. Все совпадения будут подсвечены жёлтым. Поиск работает только в текущей таблице.

Как сгруппировать записи по статье затрат или единице измерения?

Перетащите заголовок колонки на панель группировки (ПКМ → «Показать панель группировки»). Записи автоматически сгруппируются. Чтобы раскрыть все группы — нажмите «Раскрыть все» на панели.

Как открыть несколько окон рядом (не вкладками)?

Перетащите вкладку за её заголовок → появится навигационная панель с зонами → отпустите в нужную зону. На двух мониторах можно перетащить окно на второй экран — оно автоматически развернётся.

Почему некоторые кнопки в интерфейсе неактивны (серые)?

Причины:

  • У вашей роли нет прав на это действие
  • Действие недоступно в текущем контексте
  • Вы работаете с некалькулируемым элементом, а кнопка относится к калькуляции
Что означают серые (недоступные) поля при редактировании элемента?

Серым выделены поля, недоступные для редактирования, потому что это агрегированные индикаторы (у калькулируемых элементов), системные поля или поля, зависящие от других значений.

Импорт и экспорт данных

Как обновить цены в базе без ручного ввода?
1. «Экспорт → Стандартный (актуализация цен)» → сохраните файл  
2. Обновите цены в колонках Индикаторов (только в незащищённых ячейках)  
3. «Импорт → Актуализация данных» → выберите обновлённый файл  

Изменения применятся только в текущем измерении.

Ролевая модель

Какие права у моей роли?
  • Руководитель: полный доступ ко всем разделам
  • Специалист: редактирование справочников, элементов, измерений; импорт и экспорт с индикаторами
  • Мониторщик: только просмотр и экспорт с индикаторами; импорт разрешён
  • ПТО / Планировщик: просмотр, импорт, экспорт без индикаторов

Просмотр всех данных доступен всем ролям.
